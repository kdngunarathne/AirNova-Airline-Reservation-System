# AirNova Airline Reservation & Ticket Management System

## Major Scenario
Flight Booking and Passenger Management

## Description
AirNova is a Java desktop application developed to manage airline reservations, passenger records, ticket bookings, payments, and reports through a centralized system.

## Technologies
- Java Swing
- MySQL
- JDBC
- Jasper Reports
- GitHub

## Features
- User Authentication
- Flight Management
- Passenger Management
- Ticket Booking
- Payment Processing
- Dashboard Analytics
- Revenue Reports
